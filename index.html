Three Core Engines

🧠

Grounding Engine

RAG reliability solved. Uses a reasoning LLM to verify factual claims against sources, bypassing the 100% false-positive rate of embedding-based cosine similarity.

  • Claim Extraction & Verification
  • Source Ranking (Authority/Freshness)
  • Conflict Resolution
🔐

Guard Engine

Agent identity and governance via HMAC JWT tokens and declarative allow/deny glob policies.

  • Agent Identity Management
  • Declarative Glob Policies
  • < 0.01ms Verification Latency
🗄️

Audit Store

Tamper-evident log ensuring regulatory compliance (EU AI Act, HIPAA). An append-only SQLite WAL log with a continuous SHA-256 Hash Chain.

  • SHA-256 Hash Chain Integrity
  • Filterable Queries
  • Pure JS SQLite (Zero native deps)

End-to-End Governance

Protecting your application before and after the LLM call.

Output Governance

Citation checking, regex-based PII scanning, and custom pattern blocking to catch obvious issues before grounding.

Document Governance

Pre-filters source documents by status, effective/expiry dates, supersession rules, and versioning.

Escalation Engine

Post-verification actions: Pass, Flag, Block, or Correct (re-prompt LLM to fix the response).
