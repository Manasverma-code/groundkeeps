Two Engines, One API

🔍

Grounding Engine

Real-time hallucination detection using reasoning-based verification. Extracts claims, checks against sources, ranks by freshness and authority.

🛡️

Guard Engine

Agent identity with JWT tokens. Declarative allow/deny policies with glob patterns. Real-time action verification before execution.

📋

Audit Store

Append-only WAL-based log with SHA-256 hash chains. Detect tampering instantly. Full compliance reporting (EU AI Act, HIPAA, SOC 2).

🔌

Any LLM Provider

Swap between OpenAI, Anthropic, Gemini, Groq, Ollama, and more via env vars. Zero code changes. Works with local or cloud models.
